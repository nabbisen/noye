# Roadmap

The roadmap lives at the repository root, not inside this book — see
[`ROADMAP.md`](https://github.com/nabbisen/noye/blob/main/ROADMAP.md).

It records work that has been intentionally deferred and the reason
each item was set aside. Treating that "why we haven't built this"
catalogue as part of the design is one of the project's principles —
features that aren't shipped are still decisions worth documenting.
